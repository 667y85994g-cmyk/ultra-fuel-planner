# Pre-2026 brand archive

Pre-migration screenshots and assets captured before the brand migration
(Prompts 01 → 07, Q2 2026).

## Contents

- `baseline-pre-03a/` — screenshots of every live surface captured before
  Prompt 03a landed. Includes home, planner, results, print, log, and
  how-to-fuel. Used as the before state in the brand-migration PR series.

## Why archived

The migration introduced the full paper/ink/ochre token system, outlined
wordmark lockups, static favicons, and the editorial voice sweep. These
screenshots document the product as it was before any of that landed.

For the current implementation state, see `docs/brand/IMPLEMENTED.md`.
